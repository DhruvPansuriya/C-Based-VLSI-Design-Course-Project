record its ten handwritten cases for Examples 1, 2 and 4. They are preserved
unchanged as historical evidence, not presented as a fresh run.

For the implemented public pipeline's twenty cases across Examples 1–7, read
[the T11 evidence checkpoint](../checkpoints/2026-11-23-t11/README.md).
