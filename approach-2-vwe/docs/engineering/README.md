# docs/engineering/ - build notes

Notes written while we built VWE, one per task of the plan. They record what was built, how it was
checked and any limits we found. They are kept for reference; the reports in `../report/` are the
place to start.

* `T02_ADMISSION.md` to `T18_EVAL.md`: one note per task.
* `METHODOLOGY_WALKTHROUGH.md`: the method explained against the code.
* `IMPLEMENTATION_REPORT.md`: which part of the method is implemented where.
* `EVAL_P3.md`: how the HLSCheck (Approach-1) cases were turned into VWE tasks.
* `IMPORT_REVIEW.md`: corrections we made to the first prototype before building on it.
* `plan/`: the original task plan, progress table and open questions.
