# T21 — FIFO temporal track (Approach 2)

**Priority:** nice · **Depends on:** T08, T12 · **Effort:** about 3 days

## Goal

The synchronous FIFO case study from the draft: verify that a fix to a FIFO model in C meets temporal properties (no overflow or underflow, order preservation, count consistency) using k-induction.

## Steps

1. **Model:** `examples/fifo/fifo_p0.c` (buggy: the full flag is off by one), `fifo_ref.c` and candidates v1–v4. One `step(state*, push, pop, din) -> dout` function; the state is a struct with `buf[DEPTH]`, `rd`, `wr`, `count`.
2. **Template invariants (`vwe/fifo/templates.py`):** a fixed list of parameterised invariant templates: `0 <= count <= DEPTH`, `count == (wr - rd) mod DEPTH` (+ full-flag reasoning), `full <-> count == DEPTH`, `empty <-> count == 0`, and order preservation via a ghost "two tagged elements" scheme (push tag A then tag B, so A must pop before B).
3. **Checking:** a harness with a nondeterministic initial state constrained by the invariant, one `step`, and assert the invariant (the induction step); plus the base case from reset. Use CBMC; if `--k-induction` in ESBMC is used, it is for confirmation only (the AGENTS.md rule).
4. **R26 exception:** the LLM may receive a **structural summary** of `P1` (state variable names and types, never the code body) to instantiate the templates. This is the **only** documented exception to "no LLM sees P1". Implement it as `vwe/llm/context.py::FifoStructSummary`, generated by pycparser from the struct definition only, and test that no statement text leaks (reuse the canary test with the canary inside the `step` body).
5. **Verdicts:** an invariant that fails the base case or induction step and has a concrete counterexample trace from reset → REJECT E1 (if it is outside the request) or E2; all invariants inductive → ACCEPT E2; induction fails but no reachable counterexample within the bound → UNDECIDED ("invariant not inductive").

## Acceptance criteria

```bash
python scripts/run_fifo_case.py   # v1 ACCEPT, v2 REJECT (overflow), v3 REJECT (order), v4 UNDECIDED or ACCEPT (explained)
pytest -q tests/test_fifo_isolation.py
```
