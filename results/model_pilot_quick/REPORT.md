# Quick multi-model HLS optimization pilot

One educational eight-element prefix-sum kernel, one saved attempt per model. The three local models receive byte-identical system/user messages and the same generation settings. GPT-6.1-Sol is a fresh-context Codex reference using the same instruction text; its sampling controls are not exposed.

All candidates are preserved without repair. Inconclusive/unsupported results are not classified as semantic errors. This pilot demonstrates the pipeline, not model accuracy or a reliable model ranking.

Hardware: fresh Bambu + Verilator + Yosys + OpenSTA, Nangate45 typical, common 10 ns clock. Mapped pre-layout ASIC estimates. Each successful implementation has sixteen passing RTL calls. Correct candidates also pass 264 compiled-C comparisons; accepted SMT queries are replayed.

Protocol and exact prompt: `protocol.json`, `prompt.txt`. Each model directory retains requests, raw responses, unmodified candidate C, model/runtime provenance, verification records and native checks. SmolLM2 GGUF is a bartowski community conversion of the Hugging Face model. Qwen and IBM weights are from their official GGUF repositories. No paid inference API was called.

Reproduce the local pilot with `python scripts/run_model_pilot.py`. Saved first responses are reused rather than resampled. The Codex response is retained separately and is not silently regenerated by that command.

## Separate Qwen native diagnostic

The formal result remains **unsupported**, because the candidate calls a compiler builtin without a model in our frontend. This is not a formal HLSCheck refutation. An independently compiled execution of the exact unmodified source nevertheless confirms a semantic mismatch:

- Input a: `[1, 1, 1, 1, 1, 1, 1, 1]`.
- Original out: `[1, 2, 3, 4, 5, 6, 7, 8]`.
- Qwen out: `[0, 0, 0, 0, 0, 0, 0, 0]`.

Evidence: [audit summary](independent_audit/summary.json), [native witness harness](independent_audit/qwen_native_witness.c). The builtin stores the addition result and returns an overflow flag; assigning that flag to out overwrites the sum with zero for a[i]+0. No candidate was repaired.
